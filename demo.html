Overview

Logical reasoning meets reinforcement learning.

Key contributions: (1) inference-augmented feature vector encoding provably safe/mine deductions, (2) shaped reward balancing progress and outcome, (3) dual ε strategy combining cross-episode decay with intra-episode adaptive reduction — together lifting win rate from 0% to 69.4%.

Classic Minesweeper is partially observable, demands logical deduction, and delivers sparse terminal-dominated rewards — a challenging combination for RL. We formulate it as a tabular MDP and train a SARSA(λ) agent with a hand-crafted 10-dimensional feature vector. The feature design is central to performance: three features (f8–f10) encode real-time constraint-propagation results, letting the linear function approximator leverage logical inferences that would otherwise require a larger network.

We run a systematic 2×2 ablation over exploration strategies (cross-episode decay × intra-episode adaptive scaling) and a separate λ sweep. The best configuration — SARSA(λ=0.8) with Decay+Adaptive ε — achieves 69.43% ± 0.41% greedy win rate across 3 seeds on standard 9×9/10-mine difficulty, compared to 0.00% for a random baseline. Conditional on surviving the unavoidable ~12.6% first-click mine deaths, the agent wins 79.48% of games where it has any agency.

Method

Four design choices, measured carefully.

Each component was developed and ablated independently: the environment MDP, the feature representation, the reward shape, and the learning algorithm with exploration.

Step 01

Environment Design

Standard 9×9/10-mine grid as a discrete MDP. BFS cascade reveals all connected zero-number cells on a single action, matching the real game and giving the agent dense informational updates per step.

state → map[9×9] ∈ {−1, 0…8, 9}
action → (row, col) ∈ hidden cells
terminal → win | mine hit
Step 02

Feature Engineering

10-dimensional φ(s, a) combining local danger statistics (f1–f7) with three logical inference features (f8–f10) derived from single-pass constraint propagation. The inference features are the key differentiator.

Q(s, a) = w · φ(s, a) ∈ ℝ¹⁰
Step 03

Reward Shaping

Sparse terminal rewards (+10/−10) supplemented with a small per-cell safe-open bonus (+0.05 × cascade size) to provide a learning signal before episodes conclude. A repeat-click penalty (−0.5) prevents degenerate loops.

R ∈ {−10, −0.5, +0.05·N, +10}
Step 04

SARSA(λ) Training

On-policy eligibility traces propagate credit back through the episode. The linear approximator stays interpretable while the λ-weighted trace enables multi-step credit assignment beyond single-step TD.

e ← γλe + φ(s,a)
w ← w + α·δ·e

Reward Design

Four distinct reward events balance exploration incentive against outcome quality.

−10.0

Symmetric to win reward, teaching mine avoidance.
−0.5

Statistical Features (f1–f7)

Local geometry and global board statistics that capture the spatial context around the candidate cell.

FeatureDescription
f1Hidden-neighbor ratio (÷8)
f2Adjacent number sum (÷64)
f3Danger estimate: f2 ÷ f1 ÷ 8
f4Completely isolated (no revealed neighbors)
f5Global hidden-cell ratio
f6Global detonated-mine ratio
f7Bias = 1.0 (linear model intercept)

Inference Features (f8–f10) — Key Innovation

Single-pass constraint propagation: if a number cell's value equals its hidden-neighbor count, all those neighbors are mines. If it equals its known-mine count, remaining hidden neighbors are safe.

FeatureDescription
f8Logically safe: constraint propagation proves no adjacent mine
f9Logically a mine: constraint propagation proves mine present
f10Max remaining-mine probability from neighboring constraints
# f8/f9: single-pass deduction if hidden_count == cell_number: → all hidden neighbors are mines (f9=1) if known_mines == cell_number: → remaining hidden are safe (f8=1) # f10: continuous danger score score = (remaining_mines) / (remaining_hidden) f10 = max(score for each neighbor)

System Architecture

From board state to optimal action.

The agent's decision pipeline: the visible board is converted to per-action feature vectors, the SARSA(λ) model scores each candidate, and ε-greedy exploration selects the final action.

Component 01 — Feature Design

Inference-Augmented Representation

f8/f9 are binary flags from constraint propagation; f10 is a continuous mine-probability estimate. Together they give the linear model a "logical reasoning" shortcut that would otherwise require a deep network.

f1–f7 Statistical + f8–f10 Inference
Component 02 — Learning

On-Policy Eligibility Traces

SARSA(λ) accumulates a trace e over the episode, distributing the TD error back to recently visited (s,a) pairs. λ=0.8 balances multi-step credit without the variance of full Monte Carlo returns.

SARSA (on-policy) → Trace λ=0.8
Component 03 — Exploration

Dual ε Strategy

Cross-episode exponential decay (0.3→0.05) reduces exploration as the agent learns. Within each episode, adaptive scaling by (1−opened_ratio)² concentrates exploration at game start when information is least available.

Decay (inter-ep) × Adaptive (intra-ep)

Exploration Mechanism

Dual ε: the key contribution.

Two orthogonal exploration dimensions — cross-episode and intra-episode — correspond to two fundamental RL modes: the agent's interaction with itself (how confident am I?) and with the environment (how much do I know right now?). Combining both yields the best win rate (69.43%) and smallest variance (±0.41%).

📈

Decay ε  — Interaction with Self

The decay schedule reflects the agent's growing competence over training. Early on, the agent knows almost nothing — random exploration is efficient because any information is useful. As more episodes accumulate, the learned weights become reliable, so the agent should trust itself more and explore less. We implement this as an exponential decay across episodes: ε decays from 0.3 → 0.05 over ≈3 600 episodes and remains constant thereafter.

This is an agent asking: "How much do I still have to learn overall?" The answer shrinks monotonically as training progresses. In RL terms, this belongs to the dimension of self-interaction — the agent regulating its own exploration based on its assessed capability.

εbase ← max(0.05, 0.3 × 0.9995episode)
🌍

Adaptive ε  — Interaction with Environment

The adaptive schedule reflects the amount of information currently visible on the board. At the very start of a game, almost all 81 cells are hidden — the agent has little context to make informed decisions, so random exploration costs little and may reveal useful patterns. As more cells are opened through BFS cascade, numbers accumulate and constraint propagation can identify safe/mine cells with certainty. At this point, the model's features (f8–f10) become highly informative and the agent should exploit them.

This is the agent asking: "How much does the environment currently tell me?" The answer grows within each game as cells are revealed. In RL terms, this belongs to the dimension of environment-interaction — scaling exploration based on the richness of the observable state.

εeff = εbase × (1 − opened_ratio)²  ,   ratio = revealed / 81

Two modes of exploration in RL — The combination is principled. Decay addresses the standard exploration-exploitation trade-off across an agent's lifetime: it is calibrated to model competence, not to any individual game. Adaptive addresses the same trade-off within a single episode: it is calibrated to per-step observability. Neither mechanism alone can solve both problems — Decay cannot distinguish a fully-revealed board from a fresh one; Adaptive cannot lower its floor as the model matures. Together they form a two-axis control: one axis tracks training progress, the other tracks in-game information.
